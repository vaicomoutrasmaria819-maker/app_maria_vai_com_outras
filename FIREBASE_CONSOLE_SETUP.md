# ⚠️ Este arquivo foi substituído

O conteúdo deste guia (usuários criados manualmente em Authentication,
regras baseadas em `request.auth.uid` direto do Firebase Auth) descrevia
uma versão anterior do projeto, que usava o provedor de Email/Senha do
Firebase Authentication.

O projeto agora usa autenticação própria com **bcrypt + Cloud Functions +
Custom Tokens**. Veja o guia atualizado em [`FIREBASE_SETUP.md`](./FIREBASE_SETUP.md).
